# Dados de demonstração

As amostras incluídas nesta cópia foram criadas por gerar_demo.py, sem leitura de planilhas, bancos, fotos ou logs operacionais. Pessoas, matrículas, endereços, telefones e ordens são inventados. Fotos do app são desenhos locais; os links de amostra dos ETLs usam example.invalid e não apontam para conteúdo real.

Não existe histórico Git copiado nem remote configurado. Nada foi enviado ao GitHub durante a preparação. Os READMEs originais dos ETLs descrevem regras operacionais e referências históricas; os resultados desta demonstração são registrados separadamente em VALIDACAO.md.

As entradas de exemplo foram geradas exclusivamente nesta pasta. A reexecução do gerador recusa sobrescrever arquivos existentes. Nunca substitua as amostras desta cópia por dados internos antes de publicar.
